# Подсчёт подтверждённых заявок

Сайт отправляет в `window.dataLayer` событие `booking_success` только после успешного ответа `/api/bookings` с номером сохранённой заявки. Событие не отправляется при ошибке проверки полей, отказе сервера, сетевой ошибке или срабатывании скрытого антиспам-поля. Повторная обработка того же номера заявки не создаёт второе событие в текущем документе.

Пример события:

```js
{ event: "booking_success", form_type: "appointment" }
```

Значения `form_type`: `appointment` — общая форма записи (включая запись к врачу, на исследование и выезд медсестры); `callback` — обратный звонок; `family_declaration` — заявка на декларацию. Полей с именем, телефоном, датой рождения, комментарием, врачом, исследованием или номером заявки в этом событии нет.

## Настройка GTM / Google Ads

После публикации кода создать в GTM триггер «Пользовательское событие» с точным именем `booking_success` и привязать к нему существующий тег конверсии. При необходимости разделять формы переменной уровня данных `form_type`.

Отключить прежние триггеры этой конверсии по нажатию кнопки, отправке формы, `gtm.formSubmit` или `form_submit`, чтобы не считать невалидные попытки и не задваивать заявки. Если конверсия импортируется из GA4, переключить соответствующее ключевое событие и импорт; не учитывать одну заявку одновременно через прямой тег Ads и импорт GA4.

Автоматический `form_submit` может по-прежнему появляться в аналитике как взаимодействие с формой. Он не подтверждает сохранение заявки и больше не должен использоваться для подсчёта лидов. Этот код не меняет настройки контейнера GTM или аккаунта Google Ads сам по себе.

Перед публикацией контейнера проверить в Tag Assistant: неполный телефон — нет `booking_success`; ошибка сервера — нет события; подтверждённая заявка — одно событие и одно срабатывание нужного тега. Использовать согласованный тестовый сценарий, чтобы не создавать случайные заявки в рабочей базе.

Событие подтверждает сохранение заявки, но не доставку уведомления по email, дозвон пациенту или согласование приёма. Блокировщик аналитики может помешать отправке в Google, не влияя на работу формы.
