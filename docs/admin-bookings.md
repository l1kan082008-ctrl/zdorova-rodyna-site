# Заявки в адмінпанелі

`/admin/bookings` показує статистику та компактний список по 25 заявок. На широкому екрані кожна заявка займає один рядок; на телефоні поля переносяться в компактний блок. Деталі відкриваються окремою кнопкою. Статус можна змінити в рядку, видалення доступне в деталях і потребує підтвердження.

Категорії мають сталі кольори: однакові у статистиці, лівій смузі та підписі категорії в рядку. Заявки зі статусом «Нова» мають легке пульсування фону; після зміни статусу воно зникає. Під час наведення, роботи з клавіатури або відкриття деталей пульсування зупиняється. Кнопка «Пульсація нових» вимикає його для цього браузера; налаштування зберігається локально. За системного налаштування зменшеного руху залишається лише статичне підсвічування.

## Підрахунок

- Стандартний період — останні 30 календарних днів разом із сьогоднішнім днем. Є сьогодні, 7 днів, усі збережені та власний діапазон.
- Період визначається за датою створення заявки в часовому поясі `Europe/Kyiv`, обидві дати включні.
- Статистика рахує всі збережені заявки за період, без попереднього обмеження у 250 записів. Вона включає скасовані заявки; видалені вручну або автоматично за чинною політикою зберігання не враховуються. «Усі збережені» не означає історію за весь час роботи сайту.
- Кожна заявка належить одній категорії. Категорія визначається за джерелом, послугою, структурованим переліком досліджень і точними назвами/аліасами прайсу. Довільний коментар пацієнта не змінює категорію. Змішані та невизначені набори належать до «Інше».
- Пошук, категорія та статус фільтрують список, але не загальну статистику періоду. Натискання категорії або статусу в статистиці вмикає відповідний фільтр. «Усього заявок» скидає фільтри списку.
- Список оновлюється після зміни статусу, видалення, зміни фільтрів або натискання «Оновити». Автоматичного опитування сервера немає.

## API та перевірки

Авторизований `GET /api/admin/bookings` приймає `from`, `to`, `q`, `category`, `status`, `page`, `pageSize` (до 100) та повертає `{bookings, stats, total, page, pageSize, totalPages}`. Контактні дані завантажуються лише для поточної сторінки; статистика формується на сервері. Відповідь не кешується. `PATCH` і `DELETE` повертають `{success:true}`, після чого клієнт перечитує активний список.

Перевірки логіки: `node --test tests/admin-booking-statistics.test.mjs tests/booking-storage.test.mjs`. Тести використовують ізольовану SQLite у пам’яті, без робочої бази. Візуальна QA-вибірка в `work/admin-bookings-dashboard-qa/` містить лише вигадані дані та не входить у публікацію.
