# Подальший вибір міста

Погоджений напрямок: при першому вході показувати «Оберіть ваше місто»; обране місто визначає доступні послуги, ціни, лікарів, інформацію та сторінки. Звягель також має отримати окремий міський каталог. Потрібно окремо спроєктувати перемикання, збереження вибору та переходи за прямими посиланнями.

Поточна зміна: Броди прибрано з перемикача міст та списку відділень для онлайн-запису. У контактах залишається лише інформаційний блок. Адміністративне редагування відділення збережено. Міська фільтрація всього сайту ще не реалізована.
